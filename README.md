
# Copper City Makerspace

## Project Description
This is a multi-page website created for my GIT 215 Code-Along 5 assignment at Arizona State University.

The website provides information about Copper City Makerspace, including its mission, workshops, tools, and membership options.

## Website Pages
- index.html - Home
- about.html - About Us
- workshops.html - Workshops & Tools
- memberships.html - Membership & Visit

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries
- GitHub Desktop
- Visual Studio Code
- GitHub Pages

## Project Workflow
1. Forked the starter repository on GitHub.
2. Cloned the repository using GitHub Desktop.
3. Opened the project in VS Code.
4. Created separate HTML pages.
5. Updated navigation using relative links.
6. Added mobile-first CSS and a responsive media query.
7. Saved changes and prepared the website for publication using GitHub Pages.

## Responsive Design
The website uses a mobile-first approach. On smaller screens, the navigation and content cards are stacked vertically. On screens 768px and wider, they are displayed horizontally.
